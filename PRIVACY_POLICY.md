# Expiry — Política de Privacidad

**Última actualización: 12 de septiembre de 2026**

Esta Política de Privacidad explica cómo **Expiry**, desarrollada bajo **Pagrey Labs**, trata la información cuando utilizas la aplicación Android para gestionar fechas de caducidad.

## 1. Resumen

Expiry está diseñada con un enfoque de privacidad por defecto. No requiere crear una cuenta ni iniciar sesión para utilizar sus funciones principales. Los productos, fechas, categorías y registros introducidos por el usuario se almacenan principalmente de forma local en el dispositivo.

Expiry no vende los datos personales de los usuarios.

## 2. Información que puede gestionar la aplicación

### Datos introducidos por el usuario

Puedes introducir información de productos, como nombre, categoría, fecha de caducidad y registros relacionados con su consumo o descarte. Esta información se utiliza para proporcionar las funciones de inventario, búsqueda, filtros, estadísticas y recordatorios.

Estos datos se almacenan localmente en el dispositivo y no se envían a un servidor de Expiry para crear una cuenta o un perfil del usuario.

### Cámara y códigos de barras

Expiry puede solicitar acceso a la cámara para escanear códigos de barras. Las imágenes de la cámara se utilizan para realizar el escaneo y no se almacenan como fotografías por Expiry como parte de esta función.

Cuando se escanea un código de barras, la aplicación puede consultar información pública de productos a través de Internet para completar datos del producto cuando dicha información esté disponible. La disponibilidad y el tratamiento de esa información pueden depender del servicio externo utilizado.

### Notificaciones

Expiry puede solicitar permiso para enviar notificaciones locales relacionadas con recordatorios de caducidad. Estas notificaciones se generan para las funciones de la aplicación y no requieren crear una cuenta.

## 3. Publicidad y servicios de Google

La versión gratuita de Expiry puede mostrar publicidad mediante **Google Mobile Ads (AdMob)**. La versión Premium, cuando esté disponible y activada para el usuario, está diseñada para no mostrar publicidad.

Cuando se utiliza Google Mobile Ads, Google puede tratar determinados datos técnicos y de uso necesarios para publicidad, medición, seguridad y funcionamiento del servicio. Dependiendo de la configuración y del consentimiento aplicable, esto puede incluir dirección IP, identificadores de publicidad o de aplicación/dispositivo, interacciones con la aplicación e información de diagnóstico y rendimiento.

Google indica que su SDK de Google Mobile Ads puede recopilar y compartir automáticamente dirección IP, interacciones del usuario, información de diagnóstico e identificadores de dispositivo o cuenta para fines de publicidad, analítica y prevención del fraude.

Para usuarios del Espacio Económico Europeo, Reino Unido y otras regiones en las que resulte aplicable, Expiry utilizará los mecanismos de consentimiento de Google correspondientes antes de utilizar datos para publicidad personalizada cuando sea necesario. Las opciones de consentimiento podrán modificarse o retirarse cuando la normativa aplicable lo permita.

Para más información sobre el tratamiento de datos por Google, consulta la documentación y las políticas de privacidad de Google.

## 4. Proveedores externos

Expiry puede utilizar servicios de terceros para funciones concretas, incluyendo:

- **Google Mobile Ads (AdMob)** para publicidad en la versión gratuita, cuando esté habilitada.
- Servicios externos de información pública de productos para completar datos después de un escaneo, cuando esta función esté disponible.

Estos proveedores pueden tratar información conforme a sus propias políticas de privacidad y condiciones.

## 5. Datos que no recopilamos para crear una cuenta

Expiry no requiere:

- Nombre real del usuario.
- Dirección postal.
- Número de teléfono.
- Contraseña.
- Cuenta de usuario de Expiry.
- Datos bancarios para utilizar las funciones básicas.

Expiry tampoco está diseñada para recopilar deliberadamente datos de salud, financieros o de ubicación precisa.

## 6. Conservación y eliminación

Los datos de productos y registros almacenados localmente permanecen en el dispositivo mientras el usuario los conserve. El usuario puede eliminarlos desde las funciones disponibles de la aplicación o mediante las opciones de almacenamiento del sistema Android, según corresponda.

Si Android realiza una copia de seguridad de los datos de la aplicación de acuerdo con la configuración del dispositivo y del sistema, dicha copia estará sujeta a los mecanismos de copia de seguridad de Android y de la cuenta correspondiente.

Expiry no mantiene una cuenta de usuario en sus servidores que deba eliminarse mediante una solicitud de borrado de cuenta.

## 7. Seguridad

Expiry aplica medidas razonables para limitar el acceso a los datos almacenados por la aplicación. Las comunicaciones con servicios externos utilizados por la aplicación se realizan mediante los mecanismos seguros proporcionados por Android y dichos servicios cuando corresponde.

Ningún sistema de almacenamiento o transmisión puede garantizar seguridad absoluta.

## 8. Menores

Expiry no está dirigida específicamente a menores de edad. La aplicación no solicita conscientemente datos personales de menores para crear cuentas o perfiles.

## 9. Cambios en esta política

Podemos actualizar esta Política de Privacidad cuando cambien las funciones de Expiry, los servicios utilizados o los requisitos legales. La fecha de última actualización indicada al principio de esta página se modificará cuando se publique una nueva versión.

## 11. Información adicional sobre terceros

La información sobre el tratamiento de datos por servicios de terceros puede cambiar. Antes de utilizar funciones que dependan de esos servicios, recomendamos consultar sus políticas vigentes.

Esta política describe el tratamiento de datos de Expiry y no sustituye las políticas de privacidad de los proveedores externos.
